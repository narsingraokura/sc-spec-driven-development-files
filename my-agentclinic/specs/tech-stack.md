# Tech Stack

## Frontend
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS

## Backend
- **API**: Next.js API routes (co-located with the frontend)
- **ORM**: Prisma
- **Database**: SQLite

## Rationale
- Next.js App Router gives us server components, layouts, and file-based routing in one TypeScript-first package — satisfying Mary's requirement for a popular, reliable stack.
- Tailwind enables the polished, modern UI Steve wants without a heavy component library dependency.
- Prisma's type-safe client and migration tooling keep the data layer predictable as Susan's feature set grows.
- SQLite keeps the database zero-config and self-contained — ideal for demos and course projects.
